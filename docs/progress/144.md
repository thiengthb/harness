    cục bộ là cách giải cả hai — và `bareTree()` chưa dùng cách đó.
  - Bộ task **vượt session limit của một phiên**.

- **QUYẾT ĐỊNH đã chốt**
  - **KHÔNG khai `evals.command` vào `harness.config.json`.** `apply-to.mjs:48` seed file này
    sang project mới ⇒ mọi project mới sẽ gọi agent tốn tiền mà không ai xin. Đo bằng
    `HARNESS_CONFIG` trỏ config tạm; template không đổi một byte.
  - **Chạy trên NHÁNH, không trên `main`.** Lần chạy đầy đủ diễn ra trong repo THẬT

    hại nếu gác thủng. Sau lượt đầu: **0 file bẩn, sha y nguyên** — gác giữ.
