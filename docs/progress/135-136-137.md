## Đo từ BINARY trước, và lần này nó SỬA CẢ HAI PHÍA

Bảng markdown rút gọn nhúng trong `claude.exe` chỉ ghi `PreToolUse … can block`, nên thoạt nhìn
tưởng `TaskCompleted` (#131) **không** chặn được. Sai: bảng đó liệt kê 10/31 sự kiện. Hợp đồng
thật là **registry `summary/description`**, và nó nói ngược lại:

```
TaskCompleted        Exit code 2 - show stderr to model and prevent task completion
UserPromptExpansion  Exit code 2 - block expansion and show stderr to user only
PreCompact           Exit code 0 - stdout appended as custom compact instructions
                     Exit code 2 - block compaction
PermissionDenied     Exit code 0 - stdout shown in transcript mode
                     Other exit codes - show stderr to user only        ← KHÔNG có đường chặn
SubagentStart        Exit code 0 - JSON additionalContext shown to subagent
SessionEnd           Exit code 0 - command completes successfully
```

Hai hệ quả trực tiếp cho lô này:

- **`UserPromptExpansion` CHẶN ĐƯỢC** (`exit 2` = nuốt lệnh gõ tay của người dùng). `observe.mjs`
  khai `declareFailMode(1)`, tức hook hỏng → exit 1 → *"show stderr to user only"*. Một lời
  quan sát không bao giờ được phép ăn mất một lệnh của người.
- **`PermissionDenied` KHÔNG có đường chặn.** Nó thuần tuý là quan sát — đúng như #137 mô tả,
  và nay có bằng chứng thay vì suy đoán.

## Hai chỗ một con số sẽ nói dối

### ① "ĐỒNG THỜI" không phải TỔNG (#136)

`AGENTS.md` đặt trần <5 giây ở `SubagentStop` với lý do *"nhân với tối đa **16** agent song
song"*. Con số 16 **chưa ai đo**, và bản rà 2.1.224 ghi vendor đã bỏ trần 200 subagent/phiên.

Đếm `starts` rồi gọi nó là "đồng thời" là phép gộp sai: ba lần khởi động rải rác một tuần không
phải ba agent cùng lúc. `slotCounters` duyệt hai loại mốc theo **thứ tự thời gian** và lấy đỉnh.

Vì thế **`SubagentStop` cũng phải gọi `observe`** — một mình `Start` không nói được "đồng thời".
Thiếu mốc kết thúc thì đỉnh **chỉ có thể cao hơn sự thật**, nên `unpaired` được in cạnh nó thay
vì bị nuốt.

### ② `reason: "hook"` là lần chặn của CHÍNH TA (#137)

Tập giá trị `reason` của vendor có cả `hook`. Gộp nó vào *"vendor chặn việc thật"* là **tự đếm
mình hai lần** — và thổi phồng đúng con số đang định dùng để tranh luận rằng vendor cản việc.
`L0005`, phía dễ chịu. Hai cột riêng, có ca test ép chúng khác nhau.

## Chi phí đã biết, không giấu

`SubagentStop` nay chạy **hai** hook. Trần ô đó là <5 giây; sàn runner đo được **91ms**; thêm
một spawn ~60–90ms là **~2%** trần. Và nếu gate ở đó **chặn**, lời gọi `observe` sau nó có thể
không chạy ⇒ thiếu mốc `stop` ⇒ `unpaired` tăng. Con số đó được in.
